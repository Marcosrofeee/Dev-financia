# 💰 Dev Finance

Aplicação web de controle financeiro pessoal desenvolvida com HTML, CSS e JavaScript puro.

O projeto permite cadastrar e organizar entradas e saídas, acompanhar o saldo total e visualizar os gastos por categoria de forma simples e intuitiva.

## ✨ Funcionalidades

* ➕ Cadastro de novas transações
* 🗑️ Exclusão de transações com confirmação
* 💰 Cálculo automático de saldo, entradas e saídas
* 🔎 Busca de transações por descrição
* 🏷️ Filtro por categoria
* 📅 Registro e formatação de datas
* 💾 Persistência dos dados com LocalStorage
* 📊 Gráfico de gastos por categoria
* 🌙 Modo escuro
* 🔔 Notificações de sucesso
* ✅ Validação dos campos do formulário
* 📱 Layout responsivo para dispositivos móveis
* 🎨 Ícones e identificação visual das categorias

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Chart.js
* LocalStorage
* Git e GitHub

## 📊 Gráfico financeiro

O projeto utiliza o Chart.js para apresentar visualmente a distribuição das despesas por categoria.

O gráfico é atualizado automaticamente quando uma nova transação é adicionada ou excluída.

## 🎯 Objetivo do projeto

O Dev Finance foi desenvolvido como projeto de aprendizado e portfólio, com o objetivo de praticar conceitos fundamentais de desenvolvimento web, JavaScript e manipulação do DOM.

Durante o desenvolvimento foram aplicados conceitos como:

* Manipulação do DOM
* Eventos
* Funções
* Arrays e objetos
* Métodos `filter()`, `forEach()` e `sort()`
* Validação de formulários
* LocalStorage
* Renderização dinâmica
* Responsividade
* Integração com biblioteca externa
* Organização de código

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone SEU-LINK-DO-REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd dev-finance
```

3. Abra o arquivo `index.html` no navegador.

Também é possível executar o projeto utilizando a extensão Live Server no Visual Studio Code.
